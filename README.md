# Watch Video & Earn Real Money

GitHub-ready Android project for mobile-friendly APK building.

## Included
- Rewarded Ad test flow with local demo wallet
- Banner ad
- Interstitial ad before downloads when an ad is ready
- Status Maker with image download
- Wedding Card Generator with image download
- GST Invoice Maker with GSTIN, product/ad product, quantity, rate, GST and totals
- GST Calculator
- Basic Calculator
- EMI Calculator
- Age Calculator
- Discount Calculator
- Tip Calculator
- BMI Calculator
- Quote Maker
- Name Style Maker
- Demo UPI withdrawal form

## Build on GitHub
Use Actions -> Build Android APK -> Run workflow. The generated APK is in the workflow Artifacts.

## AdMob
The project uses Google's official test App ID and test ad unit IDs. Replace test IDs with your own AdMob IDs only after testing. Do not publish with test IDs.

## Real-money production requirements
This project intentionally does NOT pretend that local wallet credits or demo UPI withdrawal are real payouts. Production earning requires:
1. Authentication
2. Server-side rewarded-ad verification
3. Secure wallet ledger
4. Anti-fraud/rate limits
5. Server-side payout integration (UPI/provider)
6. Privacy policy, terms, consent and support
7. AdMob policy compliance

Never reward users for clicking ads.
